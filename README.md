# Задание

Сверстать сайт-портфолио студии **«АРТ КАМИН»** — проектирование, изготовление и монтаж печей, каминов и барбекю под ключ. Сайт состоит из двух страниц: **Главная** и **Каталог проектов**.

## Страница «Главная»

- шапка с логотипом «АРТ КАМИН», навигационным меню (Портфолио, Проектирование, Продукты, Компания, Клиенты, Магазин), выпадающим подменю каталога («Загородный дом», «Городская квартира», «Общественные пространства» и т.п.) и иконкой корзины/личного кабинета;
- hero-блок на всю ширину с фоновым фото интерьера с камином, заголовком «Печи Камины Барбекю под ключ», подзаголовком «проектирование архитектура инженерия монтаж», слоганом «С нами легко внедряются проекты»;
- горизонтальная лента из 4 фото-карточек проектов разного формата с подписями категорий (загородный дом, интерьер, коммерческий объект, ресторан/бар);
- блок «Основатель и руководитель» — фото Ирины Новосёловой, цитата-описание философии компании и кнопка «Получить консультацию руководителя»;
- блок «Воплощение любой дизайнерской идеи» — крупная фотогалерея интерьеров с каминами и интерактивными хотспот-иконками (треугольник-«вспышка»), при наведении на которые всплывают короткие подписи-преимущества;
- кнопка-CTA по центру «Получить предварительную оценку проекта»;
- тёмный блок «Комплексная реализация проекта на любом этапе строительства» с тремя пронумерованными этапами (1 — Проектирование, 2 — Выполнение под ключ, 3 — Монтаж), с описанием каждого этапа и крупной декоративной графикой треугольника (отсылка к логотипу);
- блок «Нам доверяют» с логотипами партнёров/клиентов;
- футер с логотипом, адресом и контактами, двумя колонками ссылок (Каталог: загородный дом, городская квартира, общественные пространства, материалы; Компания: о нас, портфолио, контакты и т.д.) и иконками соцсетей.

## Страница «Каталог проектов» (Concept)

- та же шапка, что и на главной, плюс хлебные крошки («Главная / Каталог»);
- панель фильтров с выпадающими списками (тип помещения, вид камина, стиль — современный/скандинавская классика/традиционный, материал очага, размер, мощность обогрева) и кнопкой «Сбросить»;
- сетка карточек-проектов (фото камина/интерьера, иконка «избранное», отметка наличия) в 4 колонки, с возможностью подгрузки дополнительных карточек по кнопке «Показать ещё»;
- боковая панель с чек-листом характеристик («доступно на складе», «идеально для помещений с высоким потолком», «дизайн для любого интерьера» и т.п.);
- блок «Центр дизайна ARTPLAY, строение 12» с двумя фото шоурумов (Шоурум 106, Шоурум 112), адресом/описанием и кнопкой записи на встречу;
- финальный блок с кнопкой-CTA «Заказать обратный звонок»;
- футер — идентичен футеру главной страницы.

Все страницы должны быть адаптивными (есть мобильная версия для каждого блока: узкая колонка, стек карточек, сворачиваемое меню, укороченная сетка каталога 2×N).

Дизайн тёмный (чёрно-графитовый фон), с оранжево-красными акцентами (логотип, кнопки, треугольные значки-«вспышки»), крупными фотографиями интерьеров с каминами, скруглёнными карточками проектов и декоративной геометрией (треугольник как визуальный лейтмотив).

Сверстать по скриншотам страниц проекта (десктоп и мобильная версия для «Главной» и «Каталога»), приложенным к заданию.
